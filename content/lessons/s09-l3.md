# Recognize wide and narrow transformations

## What you will be able to do

## The problem

You are working with workforce and project data that will be used by another team. Your result must have a clear meaning, survive incomplete records, and be reproducible. This lesson focuses on **recognize wide and narrow transformations** within jobs, stages, partitions, and shuffles.

## Build the mental model

A narrow transformation can be computed from one parent partition; a wide one redistributes data. Map, filter, and projection are commonly narrow, while repartition and many groupings are wide.

## Worked example

Read the example before running it. Identify the input facts or columns, the relationship being expressed, and the expected result.

```python
result = people.filter("years >= 3").repartition("company_id")
```

## A mistake worth recognizing
