# Start with competency questions

## What you will be able to do

Write three workforce questions and identify the facts each one requires.

## The problem

You are working with workforce and project data that will be used by another team. Your result must have a clear meaning, survive incomplete records, and be reproducible. This lesson focuses on **start with competency questions** within modeling method.

## Build the mental model

Competency questions define what a graph must answer. Turn a business request into concrete questions about entities, time, and granularity before choosing classes. A model can be elegant yet fail the questions it was built to support.

Read the example before running it. Identify the input facts or columns, the relationship being expressed, and the expected result.

## A mistake worth recognizing

> Drawing class boxes before deciding required questions often misses relationship attributes.

Construct a small counterexample that would expose this mistake. Prefer three carefully chosen records to a large dataset whose behavior is hard to explain.

## Predict, then investigate

1. Write three workforce questions and identify the facts each one requires.
2. Identify what happens when a relevant value or relationship is missing.
3. Change one fact or row and predict which part of the result changes.
4. Explain the result using the vocabulary introduced above.
