# Stage and validate

## What you will be able to do

Explain how to distinguish a clean load from an empty load.

## The problem

You are working with workforce and project data that will be used by another team. Your result must have a clear meaning, survive incomplete records, and be reproducible. This lesson focuses on **stage and validate** within ingestion and publication.

## Build the mental model

Load into a staging graph, validate its completeness and constraints, then publish only acceptable data. Quarantine invalid records with reasons and source references. Count inputs, accepted records, and rejected records to reconcile the load.

## A mistake worth recognizing

> Silently dropping invalid records can make the resulting graph look valid but incomplete.

Construct a small counterexample that would expose this mistake. Prefer three carefully chosen records to a large dataset whose behavior is hard to explain.

## Predict, then investigate

1. Explain how to distinguish a clean load from an empty load.
2. Identify what happens when a relevant value or relationship is missing.
3. Change one fact or row and predict which part of the result changes.
4. Explain the result using the vocabulary introduced above.
