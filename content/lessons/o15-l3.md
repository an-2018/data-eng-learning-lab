# Scope optional and path work

## What you will be able to do

Compare two equivalent queries using result equality before comparing performance.

## The problem

You are working with workforce and project data that will be used by another team. Your result must have a clear meaning, survive incomplete records, and be reproducible. This lesson focuses on **scope optional and path work** within query performance.

## Build the mental model

Bind endpoints and choose graph scope before exploring expensive paths when semantics allow. Broad optional branches and unconstrained reachability can produce much larger intermediate results. Preserve the original meaning while testing alternatives.

## A mistake worth recognizing

> Moving a filter across OPTIONAL may change which incomplete records are retained.

Construct a small counterexample that would expose this mistake. Prefer three carefully chosen records to a large dataset whose behavior is hard to explain.
