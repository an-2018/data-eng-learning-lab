# Choose latest records deterministically

## What you will be able to do

Keep the latest record per key with an explicit tie-breaker.

## The problem

You are working with workforce and project data that will be used by another team. Your result must have a clear meaning, survive incomplete records, and be reproducible. This lesson focuses on **choose latest records deterministically** within window functions and deterministic deduplication.

## Build the mental model

Use row_number with a complete ordering to keep exactly one record per business key. Add a stable secondary key whenever timestamps can tie.

## Worked example

Read the example before running it. Identify the input facts or columns, the relationship being expressed, and the expected result.

```python
from pyspark.sql import Window, functions as F
w = Window.partitionBy("name").orderBy(F.col("years").desc(), F.col("company_id").asc_nulls_last())
result = people.withColumn("rn", F.row_number().over(w)).filter("rn = 1").drop("rn")
```
