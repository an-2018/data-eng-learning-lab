# Facts as triples

## What you will be able to do

Represent a person, their employer, and the employer name using three triples.

## The problem

You are working with workforce and project data that will be used by another team. Your result must have a clear meaning, survive incomplete records, and be reproducible. This lesson focuses on **facts as triples** within rdf foundations.

## Build the mental model

A triple describes one relationship: a subject resource, a predicate IRI, and an object resource or literal. A person is not the same thing as their name. Give the person an IRI so that employment, project, and contact facts can refer to the same resource. Splitting one statement into several triples allows new information without redesigning a row.

## A mistake worth recognizing

> A string containing a company name does not link to the company resource.

Construct a small counterexample that would expose this mistake. Prefer three carefully chosen records to a large dataset whose behavior is hard to explain.
