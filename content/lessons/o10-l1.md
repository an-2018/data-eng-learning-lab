# Nested shapes and paths

## What you will be able to do

Require an address only for the subset of people defined by the stated policy.

## The problem

You are working with workforce and project data that will be used by another team. Your result must have a clear meaning, survive incomplete records, and be reproducible. This lesson focuses on **nested shapes and paths** within advanced shacl.

## Build the mental model

sh:node validates a value node against another shape. A sequence path follows multiple predicates, while an inverse path follows edges backward. Choose whether a nested resource is optional separately from whether an existing one must conform.

## A mistake worth recognizing

> A nested shape does not require the property to exist without minCount.
