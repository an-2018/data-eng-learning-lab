# Blank nodes and reusable identity

## What you will be able to do

Decide whether an employee assignment that changes weekly needs a stable IRI.

## The problem

You are working with workforce and project data that will be used by another team. Your result must have a clear meaning, survive incomplete records, and be reproducible. This lesson focuses on **blank nodes and reusable identity** within rdf foundations.

## Build the mental model

A blank node says that a resource exists without assigning it a global IRI. It is useful for a local address or restriction expression. Its serialization label is not a persistent external identifier. A resource that must be joined across snapshots usually needs a stable IRI.

## A mistake worth recognizing

> Two blank nodes with similar fields are not automatically the same resource.

Construct a small counterexample that would expose this mistake. Prefer three carefully chosen records to a large dataset whose behavior is hard to explain.
