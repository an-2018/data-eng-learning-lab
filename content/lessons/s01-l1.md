## The problem

You are working with workforce and project data that will be used by another team. Your result must have a clear meaning, survive incomplete records, and be reproducible. This lesson focuses on **driver, executors, and a dataframe** within spark execution model.

## Build the mental model

The driver builds the computation and coordinates tasks. Executors perform work on partitions. A DataFrame represents a distributed table with a schema and a plan, not a local Python list. The initial labs use local mode while retaining Spark planning behavior.
