# Diagnose unsatisfiable classes

## What you will be able to do

Remove one conflicting axiom and state the meaning you lose.

## The problem

You are working with workforce and project data that will be used by another team. Your result must have a clear meaning, survive incomplete records, and be reproducible. This lesson focuses on **diagnose unsatisfiable classes** within owl restrictions and reasoning.

## Build the mental model

A class that inherits from two disjoint classes cannot have members. To debug, isolate the smallest conflicting set of axioms. Separate ontology consistency, class satisfiability, and expected classification into distinct tests.

## A mistake worth recognizing

> A reasoner timeout does not demonstrate consistency or inconsistency.

Construct a small counterexample that would expose this mistake. Prefer three carefully chosen records to a large dataset whose behavior is hard to explain.

## Predict, then investigate

1. Remove one conflicting axiom and state the meaning you lose.
2. Identify what happens when a relevant value or relationship is missing.
3. Change one fact or row and predict which part of the result changes.
4. Explain the result using the vocabulary introduced above.
