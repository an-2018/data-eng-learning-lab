# Normalize without erasing evidence

## What you will be able to do

Describe which transformations are reversible and which need source retention.

## The problem

You are working with workforce and project data that will be used by another team. Your result must have a clear meaning, survive incomplete records, and be reproducible. This lesson focuses on **normalize without erasing evidence** within semantic integration and entity resolution.

## Build the mental model

Normalize fields for comparison but preserve the original source values. Whitespace, casing policies, dates, and missing-value markers need explicit rules. Email local-part normalization needs a chosen policy; blindly rewriting all addresses can create false matches.

> A comparison value is not necessarily a replacement for the source field.
