# Absence and correlated existence

## What you will be able to do

Describe the dataset scope in which the returned people have no recorded email.

## The problem

You are working with workforce and project data that will be used by another team. Your result must have a clear meaning, survive incomplete records, and be reproducible. This lesson focuses on **absence and correlated existence** within sparql composition.

## Build the mental model

FILTER NOT EXISTS tests whether a pattern has a match under current bindings. MINUS removes compatible mappings with shared variables and has different behavior when no variables are shared. Choose deliberately rather than assuming these forms are interchangeable.

## Worked example

Read the example before running it. Identify the input facts or columns, the relationship being expressed, and the expected result.

```sparql
PREFIX ex: <https://example.org/>
PREFIX rdf: <http://www.w3.org/1999/02/22-rdf-syntax-ns#>
PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#>
PREFIX xsd: <http://www.w3.org/2001/XMLSchema#>
SELECT ?person WHERE {
  ?person a ex:Person .
  FILTER NOT EXISTS { ?person ex:email ?email }
}
```

## A mistake worth recognizing

> Absence in the queried graph is not proof that the fact is false in the world.
