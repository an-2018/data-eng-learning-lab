## The problem

You are working with workforce and project data that will be used by another team. Your result must have a clear meaning, survive incomplete records, and be reproducible. This lesson focuses on **turtle and rdf datasets** within rdf foundations.

## Build the mental model

Turtle abbreviates triples using prefixes, semicolons, and commas. A semicolon keeps the subject; a comma keeps both subject and predicate. Named graphs belong to an RDF dataset, not to an individual triple. Use TriG or N-Quads when serializing named graphs.


## A mistake worth recognizing

> The order of triples in a Turtle file does not define a query result order.

Construct a small counterexample that would expose this mistake. Prefer three carefully chosen records to a large dataset whose behavior is hard to explain.
