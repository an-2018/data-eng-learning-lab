## The problem

You are working with workforce and project data that will be used by another team. Your result must have a clear meaning, survive incomplete records, and be reproducible. This lesson focuses on **column expressions** within expressions, nulls, and types.

## Build the mental model

PySpark Column expressions build a distributed computation. Use built-in functions for common transformations instead of bringing data into Python row loops. Name computed fields explicitly.

## Worked example

Read the example before running it. Identify the input facts or columns, the relationship being expressed, and the expected result.

```python
from pyspark.sql import functions as F
result = people.select("name", (F.col("years") + 1).alias("next_year"))
```
