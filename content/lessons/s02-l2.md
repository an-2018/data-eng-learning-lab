# Select and rename columns

## What you will be able to do

## The problem

You are working with workforce and project data that will be used by another team. Your result must have a clear meaning, survive incomplete records, and be reproducible. This lesson focuses on **select and rename columns** within dataframes and schemas.

## Build the mental model

Projection controls output columns and their names. Use aliases to produce the stated contract and avoid duplicate ambiguous names after joins. Selecting the right values with the wrong schema can break a downstream consumer.

## Worked example

Read the example before running it. Identify the input facts or columns, the relationship being expressed, and the expected result.

```python
from pyspark.sql import functions as F
result = people.select(F.col("name").alias("person_name"))
```

## A mistake worth recognizing

> Column position and naming should not be left accidental in a published table.
