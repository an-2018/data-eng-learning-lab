# Existential and universal restrictions

## What you will be able to do

Explain why an Employee with no recorded employer can remain consistent.

## The problem

You are working with workforce and project data that will be used by another team. Your result must have a clear meaning, survive incomplete records, and be reproducible. This lesson focuses on **existential and universal restrictions** within owl restrictions and reasoning.

## Build the mental model

An existential restriction requires some qualifying value in every model, but the value need not have an explicit name or triple in the input. A universal restriction constrains any values that exist and does not require at least one.

## A mistake worth recognizing

> Universal restrictions can hold when there are no values at all.

Construct a small counterexample that would expose this mistake. Prefer three carefully chosen records to a large dataset whose behavior is hard to explain.

## Predict, then investigate

1. Explain why an Employee with no recorded employer can remain consistent.
2. Identify what happens when a relevant value or relationship is missing.
3. Change one fact or row and predict which part of the result changes.
4. Explain the result using the vocabulary introduced above.
