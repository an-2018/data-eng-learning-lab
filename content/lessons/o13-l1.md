# Snapshots and mapping versions

## What you will be able to do

Specify enough metadata to rebuild the same graph six months later.

## The problem

You are working with workforce and project data that will be used by another team. Your result must have a clear meaning, survive incomplete records, and be reproducible. This lesson focuses on **snapshots and mapping versions** within ingestion and publication.

## Build the mental model

Treat a source snapshot and mapping version as inputs to a reproducible transformation. Use stable identifiers based on appropriate source keys. A reproducible output also requires fixed normalization and datatype policies.

## A mistake worth recognizing

> A current source URL does not identify the exact bytes used by a historical load.

Construct a small counterexample that would expose this mistake. Prefer three carefully chosen records to a large dataset whose behavior is hard to explain.
