# Model observed and derived media facts

## What you will be able to do

Model one viewing event and one derived genre-affinity observation.

## The problem

You are working with workforce and project data that will be used by another team. Your result must have a clear meaning, survive incomplete records, and be reproducible. This lesson focuses on **model observed and derived media facts** within media audience knowledge graphs and shacl.

## Build the mental model

Viewing events, web activity, ad impressions, and derived affinities are different things. Retain the observed event separately from a score calculated from it.

## A mistake worth recognizing

> A viewing event is not an asserted preference, and an ad impression is not a completed view or click.

Construct a small counterexample that would expose this mistake. Prefer three carefully chosen records to a large dataset whose behavior is hard to explain.

## Predict, then investigate

1. Model one viewing event and one derived genre-affinity observation.
2. Identify what happens when a relevant value or relationship is missing.
3. Change one fact or row and predict which part of the result changes.
4. Explain the result using the vocabulary introduced above.
