## The problem

You are working with workforce and project data that will be used by another team. Your result must have a clear meaning, survive incomplete records, and be reproducible. This lesson focuses on **null and three-valued logic** within expressions, nulls, and types.

## Build the mental model

A null represents missing or unknown information. Comparisons with null generally yield unknown, so ordinary equality does not select missing values. Use isNull and isNotNull deliberately, and distinguish an empty string from null.

## Worked example

Read the example before running it. Identify the input facts or columns, the relationship being expressed, and the expected result.

```python
from pyspark.sql import functions as F
result = people.filter(F.col("email").isNull()).select("name")
```

## A mistake worth recognizing

> Filtering email == None is not the intended null-test expression.
