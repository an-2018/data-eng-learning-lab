You are working with workforce and project data that will be used by another team. Your result must have a clear meaning, survive incomplete records, and be reproducible. This lesson focuses on **conditional expressions** within expressions, nulls, and types.

## Build the mental model

when and otherwise express branching in a column expression. coalesce chooses the first non-null value. Make branch outputs type-compatible and explain any default value as a business rule rather than a technical convenience.

## Worked example

Read the example before running it. Identify the input facts or columns, the relationship being expressed, and the expected result.

```python
from pyspark.sql import functions as F
result = people.select("name", F.coalesce("email", F.lit("missing")).alias("contact"))
```

## A mistake worth recognizing

> Replacing null with zero can change averages and hide missingness.
