## The problem

You are working with workforce and project data that will be used by another team. Your result must have a clear meaning, survive incomplete records, and be reproducible. This lesson focuses on **partition and order a window** within window functions and deterministic deduplication.

## Build the mental model

A window keeps individual rows while calculating over a defined partition and order. The partition defines the peer group; the order defines which row is first, last, or cumulative.

## Worked example

Read the example before running it. Identify the input facts or columns, the relationship being expressed, and the expected result.

```python
from pyspark.sql import Window, functions as F
w = Window.partitionBy("company_id").orderBy(F.col("years").desc())
result = people.withColumn("rank", F.row_number().over(w))
```

## A mistake worth recognizing

> A window without an order is not suitable for choosing a deterministic latest record.
