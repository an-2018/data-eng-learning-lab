## The problem

You are working with workforce and project data that will be used by another team. Your result must have a clear meaning, survive incomplete records, and be reproducible. This lesson focuses on **schema is a contract** within dataframes and schemas.

## Build the mental model

A schema defines field names, types, and nullability. Explicit schemas make exercises and pipelines repeatable. Schema inference can change behavior when input samples change, especially for empty datasets or mixed values.

## Worked example

Read the example before running it. Identify the input facts or columns, the relationship being expressed, and the expected result.

```python
result = people.select("name", "years")
print(result.schema)
```

## A mistake worth recognizing

> A column containing numeric-looking strings is not necessarily an integer column.
