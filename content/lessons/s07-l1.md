# Choose a file contract

## What you will be able to do

## The problem

You are working with workforce and project data that will be used by another team. Your result must have a clear meaning, survive incomplete records, and be reproducible. This lesson focuses on **choose a file contract** within files, formats, and partitioning.

## Build the mental model

A file format carries both data and operational tradeoffs. Record schema, timezone, null policy, compression, partition columns, and producer version with each dataset.
