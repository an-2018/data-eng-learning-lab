## Build the mental model

A common table expression names an intermediate relation. It is useful when you must aggregate before a later join, because it makes the intended grain visible.

## Worked example

Read the example before running it. Identify the input facts or columns, the relationship being expressed, and the expected result.

```python
result = spark.sql("WITH experienced AS (SELECT * FROM staff WHERE years >= 3) SELECT company_id, count(*) AS people FROM experienced GROUP BY company_id")
```

## A mistake worth recognizing

> Putting an aggregate after a one-to-many join can silently inflate a count.
