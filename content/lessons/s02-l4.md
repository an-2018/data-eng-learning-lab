# Empty data still has structure

## What you will be able to do

Explain which schema fields remain when the output has no rows.

## The problem

You are working with workforce and project data that will be used by another team. Your result must have a clear meaning, survive incomplete records, and be reproducible. This lesson focuses on **empty data still has structure** within dataframes and schemas.

## Build the mental model

An empty DataFrame retains its schema. Pipelines should produce valid empty outputs rather than failing because no sample row exists. Test schema preservation independently from row equality.

## A mistake worth recognizing

> An empty result does not mean the query failed, but it may signal an unexpected filter.
