# Bulk load and validate in stages

## What you will be able to do

List the evidence retained for a bulk-load run.

## The problem

You are working with workforce and project data that will be used by another team. Your result must have a clear meaning, survive incomplete records, and be reproducible. This lesson focuses on **bulk load and validate in stages** within reliable ingestion, storage, and recovery.

## Build the mental model

Bulk loading optimizes placement but does not remove source contracts, mapping versions, validation, quarantine, and atomic promotion. Measure loading and index build separately.
